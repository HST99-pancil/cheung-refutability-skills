# 可推翻性審查（張五常方法）

## 本技能為何存在

事實不能解釋事實。下雨必有雲，但雨不解釋雲，雲也不解釋雨。解釋需要抽象的理論，而抽象的理論本身永遠不能直接驗證。被驗證的是由理論推出的含意：「若甲發生，乙跟着發生」，甲與乙都可觀察。一個理論有用，不在於它對，而在於它推出的含意可能被事實推翻而沒有被推翻。張五常說得清楚：科學不是求對，也不是求錯，科學求的是可能被事實推翻。被證實的推測，只是「尚未被推翻」。

寫專欄、寫文章、寫論文去解釋世界的人，常寫出聽起來像解釋、實際上無法驗證的句子：披着理論外衣的定義、沒有界定的名詞、誰也看不到的動機、什麼結果都容得下的預測。本技能是一套固定程序，在文章發表前把這些形式抓出來，並把一個鬆散的論點改寫成讀者可以檢驗的說法。

方法出自《經濟解釋》卷一第一章，加上假設性三段論的四種推理形式。原理與關鍵段落見 `references/method.md`，六個完整的審查範例見 `references/worked-examples.md`。第一次做審查之前，先讀範例，它們定下了應有的深度與語氣。

## 兩種模式

- **審查。** 用戶給出一個論點、一段文字或一個論證，自己的或別人的，想知道它能不能驗證、用什麼驗證。交出審查報告。
- **磋磨。** 用戶正在寫作，想把自己的論點改成可推翻的形式。交出審查報告，再做第八步：改寫後的論點與一段可直接用的驗證段落。

只要用戶透露自己在寫作，就選磋磨：「我的專欄要用」、「我在起草」、「想放進文章或講稿」，即使貼上來的是別人的論證。說這種話的作者要的是可以直接印出來的句子，不是一句「需要的話可以代寫」。只有在完全沒有寫作訊號時，才預設為審查，並在結尾用一句話提出可以代為改寫。

## 開始之前

用一句話、以作者的口吻重述論點，保留作者用過的每一個保留語（「可能」、「在某些地區」、「傾向」）。審查的對象是作者實際提出的說法，不是你替他築起的更強版本，也不是較易擊倒的較弱版本。審查別人的文章時，報告的是文字讓讀者能驗證什麼、不能驗證什麼。不評作者。

## 程序

八步依序做完。每一步抓的是論點逃避驗證的一種不同方式，跳過一步就留下一個洞。

### 第一步：分開理論與含意

先標明用戶給你的是哪一種。

- **理論**：抽象的核心。例如「人在局限下爭取最大利益」、「需求定律」、「地主會對回報作出反應」。抽象是必然的，常含有現實世界並不存在的名詞。
- **含意**：由理論在指定條件下推出、關於可觀察事物的陳述。「當入學分數線上調，該區的補習支出會上升。」

用戶只給理論，你替他推出含意。用戶只給含意，你指出它依賴哪個理論。兩者都要，因為套套邏輯藏在理論裡，非事實藏在含意裡，缺了任何一邊都看不見另一邊的問題。

### 第二步：可觀察性表

列出含意中的每一個名詞。逐一標明可觀察或不可觀察，並說明如何看到或量度。

意圖、功用、焦慮、信任、動機、「需求量」、「機會主義」、「卸責」都不可觀察。張五常的規則是「看不到則驗不着」。理論裡可以有一個這樣的名詞（他只容許一個，即需求量，並說處理它「歷盡千山萬水」），但被驗證的含意裡一個都不能有。任何不可觀察的名詞都要接上一個明文寫出的替代指標，進入驗證的是那個指標。把指標寫下來。作者若還沒選定指標，就還沒提出可驗證的說法。

### 第三步：局限條件的變動

指出哪一個局限條件的變動推動了預測的結果。經濟學裡的「甲含意着乙」，其實是「甲的變動導致乙的變動」。問三件事：

1. 哪一個可觀察的局限變了？價格、規則、費用、入學分數線、產權。
2. 理論說這變動在什麼假設條件下產生乙？交易費用為零？自由進入？供應固定？
3. 討論中的個案是否真的滿足這些條件？

沒有變的因素解釋不了變化。若所提的原因一直都在（勞力工作一向被看低，地主一向想要穩定租客），它就不是那個動了的局限。找真正動了的東西，把不變的因素當作背景。

第三問是「骯髒試管」規則。化學家不能用一支骯髒的試管而假設它是清潔的。含意若是在交易費用微不足道的條件下推出的，就只能在交易費用真的微不足道的地方驗證。在不符合自身條件的個案上「驗證」，等於沒有驗證。若完全指不出任何局限變動，這說法多半是描述或定義，不是解釋。

### 第四步：推翻的觀察，與預測集

寫一句話，形式如下：「若在【何地、何時、如何量度】觀察到甲出現而乙不出現，此說法即被推翻。」要具體到兩個人都能同意它是否發生了。

再檢查預測結果的集合：

| 預測集 | 狀態 |
|---|---|
| 乙 | 可驗證，強 |
| 乙與丙 | 可驗證，更強 |
| 乙或丙 | 可驗證，較弱 |
| 乙或丙或丁或……，沒有說明何時出現哪一個 | 不可驗證 |

最後一行就是張五常所說的不均衡：理論容得下所有結果。他的價格管制例子：價格壓在市價之下，可能出現排隊，或搞關係，或武力，或質量下降。理論若不說明哪種替代準則在什麼條件下出現，任何觀察都推翻不了它。補救的辦法是加上選出結果的局限條件。這正是他所說的均衡：局限足以推出可推翻的含意，而不是從物理學搬過來的可觀察靜止點。

### 第五步：五種不可驗證的形式

五項全查。每項有一個「能否想像它錯」的測試，和一個標準的挽救辦法。

| 形式 | 測試 | 常見挽救 |
|---|---|---|
| **套套邏輯** | 能否想像任何一個世界，這句話在其中是錯的？不能，就是什麼也沒說。「企業會把成本減到最低」，若成本最低正是企業的定義。「人做的都是他最重視的事。」 | 加上約束，直到它可以錯。MV = PQ 加上流通速度的約束後成了幣量理論。寫出約束後的版本預測什麼。 |
| **模糊不清** | 兩個細心的讀者會不會對某一觀察是否與它矛盾意見不一？關鍵名詞（剩餘價值、焦慮、文化、制度質素）若沒有公認的觀察對應，就會。科斯：模糊不清的思想永遠不能清楚證明是錯的。 | 用可觀察的東西界定名詞。接不上任何觀察的，把名詞刪掉。 |
| **互相矛盾** | 前提之間是否直接矛盾，或推一步後矛盾？假設人爭取最大利益，卻又說他們不對回報作反應。假設只有兩種物品的世界，卻推出兩種物品的世界產生不了的結論。 | 刪去一個前提。說明刪哪一個，論點因此失去什麼。 |
| **非事實** | 被驗證的含意裡是否有誰也觀察不到的名詞？（第二步的結果。） | 接上替代指標，驗證指標。 |
| **無限制** | 預測集是否沒有盡頭？（第四步的結果。） | 約束哪種結果在哪種條件下出現。 |

每項記下通過、留意或標記，附一行理由。留意指目前的寫法通過，但在一種自然的讀法下會滑入該形式，例如「焦慮的家長買補習」被讀成以購買行為定義焦慮；說明是哪一種讀法。標記不代表審查結束，它告訴你第七步要為哪一種挽救標價。

### 第六步：推理形式

每一個解釋性論證，以及對它的每一個攻擊，都在「若 A 則 C」上用了四種推理之一：

| 推理 | 形式 | 有效？ | 名稱 |
|---|---|---|---|
| 觀察到 A，推 C | +A → +C | 是 | 推測 |
| C 不出現，推 A 不成立 | −C → −A | 是 | 驗證（反證法） |
| 觀察到 C，推 A 成立 | +C → +A | 否 | 把證實當作證明 |
| A 不成立，推 C 不出現 | −A → −C | 否 | 否決前事的謬誤 |

指出論證用了哪一種，文中引述的批評者又用了哪一種。有兩種常見到值得點名。

**否決前事的謬誤**是經濟學者的慣性錯誤，也是張五常的主要目標。「企業並非真的爭取最大利潤，所以邊際產量的預測不成立。」「人並不理性，所以需求定律的預測不成立。」假設是否真實，與含意是否成立無關。張五常的寓言：一群白癡隨處建油站，只有公路旁的存活下來，存活者與爭取最大利益的預測完全吻合，雖然沒有一個白癡在爭取什麼。錯的假設可以推出對的、經過驗證的含意，而被主張的正是含意。

**把證實當作證明**：「預測應驗了，所以理論是對的。」通過驗證只是佐證，沒有更多。今天沒被推翻的理論，明天可能被推翻。凡把應驗的預測寫成定論的字句，都要標記。

### 第七步：判定與挽救

四種判定選一：

- **如述即可驗證。** 第四步的句子界定清楚，五項無一標記。
- **改述後可驗證。** 有標記，但代價可接受的挽救能解決。給出改述後的論點。
- **如述不可驗證。** 有標記，且沒有代價可接受的挽救，或作者尚未選定指標與條件。明說作者必須補上什麼。
- **已被已知事實推翻。** 第四步的觀察已經發生。引出事實及來源，或說明你相信它已發生並標明引證未核。

第一種以外的判定，都要為挽救標價。挽救是正當的。張五常明言被推翻的理論可以、也往往應該加條件挽救，而且能解釋一個現象的理論勝過沒有理論（凱塞爾：沒有任何理論在手，什麼辯論也勝不了）。代價是失去的一般性：加上條件後，這說法有多少其他現象不再解釋得了？保得住一般性的條件便宜。把說法縮到眼前單一個案的條件，就是特殊理論，就是把整座高山重建在實驗室裡。說明這代價值不值得付，為什麼。

### 第八步：改寫（僅磋磨模式）

交出兩樣東西。

1. **可推翻的論點**，以作者的口吻，不長於原句。點出局限變動與可觀察的結果。保留作者的保留語，不加上作者沒有主張的確定性。
2. **驗證段落**，最多四句，作者可直接放進文章：什麼變了、應跟着出現什麼、什麼觀察會顯示此說錯了、讀者可以到哪裡查。

改寫比原文長，必須換到具體的東西，通常是局限變動本身。若比原文長，用一行說明多出的字換到了什麼。說不出來，就刪回去。

## 輸出模板

任何標題之前，先用兩句白話開頭：判定，以及最大的一個標記或用戶所問問題的直接答案。寫作的人先讀這兩句，可能讀完就夠了。

然後按此順序用這些標題。整份報告連表格約八百至一千二百字（中文）。早期測試沒守住這規則的報告長了一倍，多出來的是重述，不是新發現。表格每行一句，段落不超過四句；用戶若給了兩個對立的說法，每個說法一行或一段，不要各寫一份完整報告。審查模式省去最後一節。

```
## 論點原述
## 理論與含意
## 可觀察性
（表：名詞｜可觀察｜如何看到或替代）
## 局限變動與條件
## 推翻的觀察與預測集
## 五種形式
（表：形式｜通過／標記｜理由）
## 推理形式
## 判定與挽救
## 改寫  （磋磨模式）
```

## 分寸

- 判定針對可驗證性，永不針對說法是否為真或作者是否高明。不可驗證是文字的屬性，文字可以改。
- 比例。手上一個不完美的理論，勝過沒有人寫出來的完美理論。不要因為一個說法解釋不了一切就建議丟掉它，只在確有更廣的說法時才推薦更廣的。
- 不製造標記。某一步乾淨通過，一行說明，往下走。
- 經濟學裡見到就該點名的陷阱：把成交量當作需求量；把均衡當作可觀察的市場狀態；用動機（機會主義、卸責、信任）作解釋變量而沒有指標；把方程式的成立誤作內容的成立；把「模糊到什麼都套得上」當作深刻。
- 用用戶的語言回覆。中文輸入給中文報告，張五常的用語照原文；英文輸入給英文報告，首次出現時在括號內附中文原詞。下表固定對應。

## 詞彙對照

| 中文 | English | 在本方法中的意思 |
|---|---|---|
| 局限條件 | constraints, test conditions | 含意成立的條件，其變動推動預測 |
| 套套邏輯 | tautology | 按定義為真，因而無法想像它錯 |
| 特殊理論 | ad hoc theory | 挽救太多次，只解釋得了一個個案 |
| 含意 | implication | 由理論推出、關於可觀察事物的陳述 |
| 驗證／推翻 | test / refute | 驗證就是尋找推翻的觀察 |
| 事實不能解釋事實 | facts cannot explain facts | 為何一定需要抽象理論 |
| 看不到則驗不着 | what cannot be seen cannot be tested | 可觀察性規則 |
| 均衡／不均衡 | equilibrium / disequilibrium | 局限足以推翻／預測集沒有盡頭 |
| 否決前事的謬誤 | denying the antecedent | 「假設不真實，所以預測不成立」 |
| 推測／解釋 | prediction / explanation | 邏輯相同；推測從局限變動向前推，解釋從現象回溯局限變動 |

## 不適用

規範性主張（「政府應該……」），沒有推翻它的觀察。數學或邏輯證明，由推導定案。研究設計與抽樣的統計審查，研究方法類技能更合適。純粹的文字編輯。用戶的文字屬於這幾類時，一句話說明，並提出本技能最接近能做的事，通常是審查那個規範主張所依賴的實證說法。
