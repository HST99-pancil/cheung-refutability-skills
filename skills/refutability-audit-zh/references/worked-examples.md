# 審查範例

六個達到應有深度的審查。前五個是張五常自己的案例，第六個是磋磨模式下的專欄論點。長度與語氣以此為準，不要加水。

---

## 範例一：「私營企業以最低成本生產」（套套邏輯）

**論點原述。** 一位經濟學者打算以數據考證私營企業的生產成本是否已是它能做到的最低成本。

**理論與含意。** 理論：企業爭取最大利潤。所給含意：觀察到的成本等於可達到的最低成本。

**可觀察性。**

| 名詞 | 可觀察 | 如何 |
|---|---|---|
| 觀察到的成本 | 是 | 帳目 |
| 可達到的最低成本 | 否 | 由理論定義為爭取利潤者所達到的成本 |

**局限變動與條件。** 沒有指出。什麼也沒變；這說法拿一個事實去比一個定義。

**推翻的觀察與預測集。** 寫不出來。任何觀察到的成本，按定義都是爭取利潤者達到的成本。預測集：所有結果。

**五種形式。**

| 形式 | 結果 | 理由 |
|---|---|---|
| 套套邏輯 | 標記 | 想像不出任何世界能推翻它 |
| 模糊不清 | 通過 | 名詞清楚 |
| 互相矛盾 | 通過 | |
| 非事實 | 標記 | 「可達到的最低」沒有獨立的觀察 |
| 無限制 | 標記 | 任何成本數字都容得下 |

**推理形式。** 沒有。沒有推理，只有重述。弗里德曼對這項考證的評語：愚蠢的問題得到愚蠢的答案。

**判定與挽救。** 如述不可驗證。挽救：加入局限變動，預測成本的走向。「企業失去壟斷保護後，單位成本在 N 年內下降」可以驗證。代價：改述後的說法只講對競爭壓力的反應，不再講靜態的成本水平。值得付；原句什麼也沒說。

## 範例二：萊斯特的貨車司機（否決前事）

**論點原述。** 萊斯特（1946）：波士頓運輸公司的主事人不知邊際產量為何物，聘人時也不用它，所以邊際生產理論錯了。

**理論與含意。** 理論：企業爭取最大利潤。含意：司機的工資等於邊際上一個司機的產出所值。

**可觀察性。**

| 名詞 | 可觀察 | 如何 |
|---|---|---|
| 工資 | 是 | 薪酬紀錄 |
| 邊際產出所值 | 部分 | 可從多聘一人的收入變動估算 |
| 主事人是否懂這概念 | 是，但無關 | 問卷 |

**局限變動與條件。** 工資率或運費變動；聘用與解僱自由；運輸市場有競爭。波士頓市場大致符合。

**推翻的觀察與預測集。** 「工資持續高於或低於邊際司機的收入貢獻，而調整人手並無障礙。」預測集一個結果。可驗證。

**五種形式。** 全部通過。含意清楚、可觀察、有限。

**推理形式。** 萊斯特的推理是 −A → −C：主事人沒有自覺地爭取最大利潤，所以工資的預測不成立。否決前事。主事人懂不懂這概念，與工資是否跟着邊際產量走無關。付得遠高於邊際產量的公司會萎縮，付得遠低的會流失司機。存活者符合預測，不論有沒有人算過，正如公路旁的油站在白癡東主沒有爭取什麼的情況下存活。

**判定與挽救。** 理論如述可驗證。萊斯特的攻擊沒有驗證它。他該做的驗證：比較各公司的工資與估算的邊際收入貢獻。他沒有做，所以他的證據沒有推翻理論。

## 範例三：需求定律（非事實，獲挽救）

**論點原述。** 物品價格下降，消費者的需求量上升。

**理論與含意。** 這是理論，還不是含意。需求量是意圖。

**可觀察性。**

| 名詞 | 可觀察 | 如何 |
|---|---|---|
| 價格 | 是 | 標價、成交價 |
| 需求量 | 否 | 意圖，真實世界不存在 |
| 成交量 | 是 | 銷售紀錄，但它不是需求量 |

**局限變動與條件。** 來自供應一方、可辨認原因的價格變動（稅、關稅、成本衝擊），確保移動的不是需求一方。條件：該物品的質量與買家的收入在期內大致不變。

**推翻的觀察與預測集。** 「供應方引起的價格下降，成交量不升，質量與收入不變，市場可自由購買。」一個結果。這樣寫出來就可驗證。

**五種形式。**

| 形式 | 結果 | 理由 |
|---|---|---|
| 套套邏輯 | 通過 | 可以想像量隨價一同下降 |
| 模糊不清 | 通過 | |
| 互相矛盾 | 通過 | |
| 非事實 | 理論標記，含意通過 | 需求量不可觀察；推出的含意在指定條件下用成交量 |
| 無限制 | 通過 | |

**推理形式。** 推測（+A → +C）然後驗證（−C → −A）。常見的錯誤是不寫明使替代合理的條件，就拿成交量當需求量。張五常：指鹿為馬。

**判定與挽救。** 改述後可驗證，如上。代價：條件（供應方原因、質量與收入固定）收窄了可以驗證的地方。便宜，因為定律仍處處適用，只是驗證的場地受限。這是張五常自己唯一容許的看不到的變量，也是接上一個這種變量的示範。

## 範例四：價格管制（無限制，加以約束）

**論點原述。** 以法令把價格壓在市價之下，會造成排隊，或走後門，或黑市，或武力，或質量下降。

**理論與含意。** 理論：價格不能定勝負時，其他準則會替代。所給含意：所列替代之一會出現。

**可觀察性。** 每一項所列結果都可觀察。問題不在可觀察性。

**局限變動與條件。** 價格上限是局限變動。條件未述。

**推翻的觀察與預測集。** 如述寫不出來：五種結果任何一種，甚至未列的第六種，都算證實。預測集沒有盡頭。這是張五常的不均衡。

**五種形式。**

| 形式 | 結果 | 理由 |
|---|---|---|
| 套套邏輯 | 通過 | |
| 模糊不清 | 通過 | |
| 互相矛盾 | 通過 | |
| 非事實 | 通過 | |
| 無限制 | 標記 | 沒有規則選出哪種替代出現 |

**推理形式。** 還不是推理。約束預測集後才成為推理。

**判定與挽救。** 如述不可驗證。挽救：加上選出結果的局限。張五常（1974）：被選用的替代準則，是在各自交易費用下租值消散最少的那一種。轉售便宜的地方，預期黑市；物品易腐、轉售難的地方，預期排隊；賣方能改變質量的地方，預期質量先降。如此每一個案只預測一個結果，可以推翻。代價：這說法現在要先有轉售費用與質量可變性的資料才能預測。值得付；沒有它就沒有預測。

## 範例五：MV = PQ（套套邏輯挽救成理論）

**論點原述。** 貨幣量乘流通速度等於價格乘成交量。

**理論與含意。** 如寫，是定義：MV 與 PQ 是同一總量從兩面看。張五常寫作 MV ≡ PQ。

**推翻的觀察與預測集。** 沒有。它不可能錯。

**五種形式。** 套套邏輯：標記。其餘通過。

**判定與挽救。** 如述不可驗證。挽救，費雪與弗里德曼在歷史上做過：加上 V 在某段期間穩定、Q 由實質因素固定的約束。於是 M 的變動預測 P 的變動。推翻的觀察：「貨幣持續擴張，V 與 Q 穩定，P 不升。」代價：理論現在只在 V 穩定的地方成立，須逐案顯示。值得付；這次挽救產生了幣量理論。教訓：套套邏輯可以是有價值的起點。不要因為它空洞而丟掉，要問什麼約束能給它內容。

## 範例六：專欄論點，磋磨模式

**用戶草稿論點。** 「馬來西亞補習中心的蓬勃，是家長焦慮推動的。」

**論點原述。** 馬來西亞補習中心的增長，源於家長對子女前途的焦慮。

**理論與含意。** 理論：家長會購買能提高所重視結果機會的教育投入。所給含意：焦慮上升，補習支出上升。左邊尚不可觀察。

**可觀察性。**

| 名詞 | 可觀察 | 如何 |
|---|---|---|
| 補習中心增長 | 是 | 註冊中心數、家庭補習支出 |
| 家長焦慮 | 否 | 心理狀態。需要指標，或一個推動它的局限 |

**局限變動與條件。** 作者沒有指出。能推動結果又看得見的候選：進入心儀中學分流或大學的分數線上調；公開考試形式轉向獎勵操練；公立學校每名學生的授課時數下降。條件：家庭收入大致穩定；補習中心自由進入。

**推翻的觀察與預測集。** 選定局限後：「分數線上調的區，每名學生的補習支出相對於沒有上調的區並無上升。」一個結果。可驗證。

**五種形式。**

| 形式 | 結果 | 理由 |
|---|---|---|
| 套套邏輯 | 留意 | 「焦慮的家長買補習」有把焦慮定義為購買行為之虞 |
| 模糊不清 | 標記 | 「焦慮」沒有公認的觀察 |
| 互相矛盾 | 通過 | |
| 非事實 | 標記 | 含意左邊不可觀察 |
| 無限制 | 通過 | |

**推理形式。** 尚無；草稿斷言了原因而沒有含意。

**判定與挽救。** 改述後可驗證。代價：改寫後的論點講的是分數線，不是感受。分數線沒動的地方，它不再解釋補習的增長。這是誠實的代價，比不可推翻的「焦慮」便宜。

**改寫。**

論點：「馬來西亞的補習潮，跟着家長心儀學位的分數線一起升。」

驗證段落：「心儀分流所需的分數一升，多操練一小時的回報跟着升，家長就買那一小時。若補習潮只關乎焦慮，分數線不動的地方補習應增長得和分數線攀升的地方一樣快。它不必如此。把各區分數線的歷史對照家庭開支調查中的補習支出，這說法就可以查。」
